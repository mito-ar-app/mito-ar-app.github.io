プライバシー・利用規約

ARむしめがねのデータの取り扱いと、ご利用にあたってのご案内です。

プライバシー

一般公開版におけるデータの取り扱いをご案内します。

開発チームが収集対象とする情報

収集対象はアプリのクラッシュ情報のみです。クラッシュ情報は、不具合の原因調査とアプリの安定性向上に使用します。

撮影した写真と観察記録

昆虫の画像判定は端末上で行います。撮影した写真と観察記録は端末内に保存されます。登録済みの観察記録は、アプリの昆虫詳細画面から削除できます。

位置情報と地図表示

位置情報へのアクセスを許可すると、撮影地点を端末内の観察記録に保存できます。また、地図画面では現在地周辺の表示に位置情報を使います。

地図の表示には地図提供者との通信が発生します。地図SDKが取り扱う情報については、提供者の案内をご確認ください。

  • Google Maps SDK for Androidのデータ開示
  • Google Maps SDK for iOSのプライバシー情報

利用規約

本アプリをご利用になる際のご案内です。

適用範囲

本規約は、モバイルアプリ「ARむしめがね」および関連サービス（以下「本アプリ」）の利用に適用されます。本アプリをご利用になる前に、本規約をご確認ください。

アプリの利用と知的財産

本アプリは、本規約および適用される法令に従ってご利用ください。本アプリのコード、デザイン、名称、ロゴなどに関する権利は、サービス提供者または正当な権利を持つ第三者に帰属します。

第三者のライブラリ、画像、モデルなどには、それぞれのライセンスが適用されます。詳細はアプリ内の「設定 → 情報 → ライセンス」をご確認ください。

写真・観察記録と個人情報

撮影した写真や観察記録、位置情報などの取り扱いについては、プライバシーをご確認ください。第三者の権利やプライバシーを尊重して本アプリをご利用ください。

端末の管理と、本アプリへのアクセスの保護は利用者ご自身で行ってください。端末の改造などにより、セキュリティが損なわれたり、アプリが正常に動作しなくなったりする場合があります。

通信と費用

地図の表示など、一部の機能にはインターネット接続が必要です。接続状況によっては利用できない場合があります。通信料やローミング料金は、ご利用の通信事業者との契約に従い利用者の負担となります。

外部サービス

本アプリは外部サービスを利用する場合があります。それぞれのサービスには提供元の条件が適用されます。

  • Firebase Crashlytics の利用規約
  • Google Maps SDK for Android のデータ開示
  • Google Maps SDK for iOS のプライバシー情報

変更・提供の終了

サービス提供者は、本アプリの内容を変更し、更新し、または提供を終了する場合があります。端末やOSの変更に伴い、引き続き利用するためにアプリの更新が必要になる場合があります。

サービス提供者は本規約を変更する場合があります。変更後の規約はこのページに掲載します。

利用にあたってのご注意

通信環境や端末の状態によって、本アプリの機能が利用できない場合があります。昆虫の判定結果や図鑑の情報は参考としてご利用ください。

本規約は、適用される消費者保護法などに基づき利用者が有する、法的に排除できない権利を制限するものではありません。
